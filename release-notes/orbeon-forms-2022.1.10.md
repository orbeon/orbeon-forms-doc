## Issues addressed

In this release, we have addressed the following issues:

* Security
    * Restrict direct serving of `.xml` assets ([\#6214](https://github.com/orbeon/orbeon-forms/issues/6214))
    * Third-party library updates
* Form Builder
    * Type with custom error message must not store `xs:string` ([\#6252](https://github.com/orbeon/orbeon-forms/issues/6252))
